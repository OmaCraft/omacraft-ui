# omacraft-ui

Shared suite chrome for OmaGrid, OmaWord, OmaDeck and OmaNotes (OmaCraft alpha 4). The plan is in
`omacraft/docs/alpha-4.md`.

- `fonts`: font tokens and the resolver.
  - `Ui` is bundled Inter and `UiStrong` is Inter SemiBold.
  - `Numeric` is Inter Tabular, which has `tnum` frozen in.
  - `Display` is Instrument Sans SemiBold, used at 16 pt and up.
  - `Mono` is the system monospace font.
  - The system UI stack and the app's script faces follow Inter. A system family counts only on an
    exact match.
  - "Use system font" (`FontOptions::use_system_font`) is off by default.
- `scale`: one type scale (`Role`) for menus, popups, dialogs, settings and the palette.
- `appearance`: Follow desktop / Light / Dark (`Mode`) and the ◐ button.
- `palette`: the command palette, which opens over the title-bar search box or with Ctrl+Shift+P / ⇧⌘P.

The crate depends on `egui = "0.37"`. Each app's `[patch.crates-io]` picks the egui it actually uses:
the storytold fork for Grid, Word and Deck, and crates.io for Notes. Apps pin this repo by revision.

## Fonts

`assets/fonts` is generated by `tools/make-fonts.py` from the pinned inputs in `tools/input`. The script
checks the input hashes, and its output is byte-for-byte reproducible. Inter comes from upstream Word's
bundled copy. Instrument Sans comes from google/fonts `ofl/instrumentsans`. Both are under the SIL OFL
1.1; see `assets/fonts/OFL-*.txt`.

## Checks

    cargo test                           # crates.io egui
    cargo test --config fork-patch.toml  # storytold fork, as Grid/Word/Deck use it
    cargo run --example detect           # what the resolver finds on this machine
